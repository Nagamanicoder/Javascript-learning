Cookies 
    -capacity: 4kb
    -Browsers : HTML4 /HTML5
    -Accesible from: any window
    -expires: manually set
    -storage location: browsers and server
    -sent with request to the server

Local storage
    -capacity: 10mb
    -Browsers : HTML5
    -Accesible from: any window
    -expires: never
    -storage location: browsers only
    -not sent with request

Session storage
    -capacity: 5mb
    -Browsers : HTML5
    -Accesible from: same tab
    -expires: on tab close
    -storage location: browsers only
    -not sent with request
